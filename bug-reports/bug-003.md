# BUG-003: В разделе "О нас" опечатка в заголовке: "Пупулярное" вместо "Популярное"

**Окружение:** Windows 11 Home 25H2, Microsoft Edge 153.0.4234.32
**Серьёзность:** Low (орфографическая ошибка в тексте, функциональность не затронута)
**Статус:** Open

## Шаги
1. Открыть сайт.
2. В верхнем меню навигации перейти в раздел "О нас".
3. Прокрутить страницу немного вниз до блока с заголовком.

## Ожидаемый результат
Заголовок отображается как "Популярное".

## Фактический результат
Заголовок отображается с опечаткой: "Пупулярное".
